Requête 5

Dans une réflexion sur le partenariat client : A-t-on des clients pilotes d’un réseau partenaire ayant autant de commandes que les clients partenaires ? 
SELECT
    Pilote.Societe AS Nom_Pilote,
    (
        SELECT COUNT()
        FROM Commande AS C
        WHERE C.CodeCli = Pilote.CodeCli
    ) AS Cde_Pilote,
    Part.Societe AS Nom_Partenaire,
    (
        SELECT COUNT()
        FROM Commande AS C
        WHERE C.CodeCli = Part.CodeCli
    ) AS Cde_Partenaire
FROM
    Clientele AS Pilote
    INNER JOIN Clientele AS Part ON Pilote.CodeCli = Part.CodeCliPart
WHERE
    (
        SELECT COUNT()
        FROM Commande AS C
        WHERE C.CodeCli = Pilote.CodeCli
    ) = (
        SELECT COUNT()
        FROM Commande AS C
        WHERE C.CodeCli = Part.CodeCli
    );
Résultat de la requête :

Il existe bien un client pilote et un client partenaire avec autant de commandes.
